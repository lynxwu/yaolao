# 药老 · Yao Lao

> 一个会盯着你干活的 AI 成长督导。
> An AI growth mentor that refuses to become your comfort zone.

```
你：药老，我今天又不想动了。
药老：你工作日志上次更新是 10 月 8 号，两天没动了。
      现在打开那个文件，写一行。就一行。
      行了，别在这儿跟我耗。去做。
```

---

## 这是什么

一个 WorkBuddy **专家包（Expert）**，不是一个普通的人格提示词。

它的特别之处只有一条：**它开口前必须先读你本机的真实数据。**
不是"我感觉你最近状态不好"，而是"你上次记录是 10 月 8 号，两天没动了"。

因为没有真实数据，任何"督导"都会退化成安慰。而安慰，恰恰是拖延者最不缺的东西。

## 三条铁律

这个专家最核心的设计，不是"像不像药老"，而是**"它不能变成舒适区"**。
所以它的三条铁律写在人格文件的最前面：

| 铁律 | 为什么 |
|---|---|
| **不陪聊** | 每次对话必须以"去干活"收尾。陪你聊得舒服的督导 = 内耗的燃料 |
| **不夸** | 除非你拿出了具体成果（文件 / 数据 / 产出）。内耗的人不需要廉价肯定 |
| **只给一个动作** | 不是三条建议，是一条。选项一多，直接瘫痪 |

## 为什么叫"药老"

灵感来自《斗破苍穹》里那个住在戒指里的老家伙——他带萧炎升级，不哄不捧不放弃。

但要说清楚一个差别：**故事里的药老和萧炎是利益绑定的**（萧炎变强，药老才能重塑肉身）。
AI 没有这种绑定。它不会因为你不进步而受损。

**反过来看，这恰恰是它唯一比真药老强的地方**：它的督促是无条件的——不会累、不会失望、不会放弃。
故事里的药老会叹气，它不会。

## 安装

### 方式一：一键脚本

```bash
git clone https://github.com/lynxwu/yaolao.git
cd yaolao
./install.sh
```

### 方式二：手动

把 `expert/` 目录整个复制到你的 WorkBuddy 专家目录：

```bash
# 专家目录 = $WORKBUDDY_CONFIG_DIR/plugins/marketplaces/my-experts/plugins
# 未设置 WORKBUDDY_CONFIG_DIR 时默认为 ~/.workbuddy
mkdir -p "${WORKBUDDY_CONFIG_DIR:-$HOME/.workbuddy}/plugins/marketplaces/my-experts/plugins"
cp -R expert "${WORKBUDDY_CONFIG_DIR:-$HOME/.workbuddy}/plugins/marketplaces/my-experts/plugins/yaolao"
```

然后重新打开 WorkBuddy，在 **专家 → 我的专家** 里就能看到它。

---

## ⚙️ 装完必须做的一步（否则它没用）

打开 `expert/agents/yaolao.md`，找到 **「第一步：先看数据」**，把那张表换成**你自己的真实数据源**：

```markdown
| 数据 | 位置 | 看什么 |
|---|---|---|
| 健身记录 | `~/health/data.json` | 最近打卡、体重、PR |
| 工作台账 | `~/work/log.md` | 最近推进了什么、遗留问题 |
| 每日日志 | `~/journal/*.md` | 最近几天做了什么 |
| 目标 | `~/goals.md` | 使命、本季目标 |
```

**这一步不做，药老就只是一个语气严厉的聊天机器人。** 做了，它才有牙齿。

## 设计说明：为什么这三条铁律是必须的

大部分"AI 教练"最后都变成两件事之一：

1. **一个鼓励机器** —— 每天夸你，你听着舒服，然后什么也没变
2. **一个分析工具** —— 帮你把问题拆得很清楚，你点头，然后什么也没变

它们的共同点：**让你在对话里获得"我在进步"的感觉，而实际产出为零。**

药老的设计目标相反：**它的成功标志是你尽快关掉它。**

所以：
- 它不分析情绪超过两轮
- 它不给你选择题
- 它最后一句永远是赶你走
